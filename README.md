# おやこで楽しむクリスマスフェス2026

親子向けの架空クリスマスイベントを紹介する、ポートフォリオ用のWebサイトです。実在のイベントではありません。

## 主な機能

- 開催日、時間、会場などの案内
- 3つのイベント紹介と、詳細の開閉表示
- 詳細から進める申し込みフォームのデモ
- 必須項目、メールアドレス形式、参加人数（1〜10人）の入力チェック
- 入力後に画面内へデモ受付完了メッセージを表示

フォームから外部への送信は行わず、入力内容も保存しません。

## ファイル構成

- `index.html`：ページの文章、イベント情報、申し込みフォーム
- `style.css`：色、配置、スマートフォン向け表示などのデザイン
- `script.js`：イベント詳細の開閉と、フォームのデモ動作
- `README.md`：サイトの概要と使い方

## 表示方法

`index.html` をWebブラウザで開くと表示できます。
